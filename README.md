# Portfolio-Project-CSC450
**Pseudocode: Java Counter Program**

1. Start the program.
2. Create the first thread to count upward.
3. Create the second thread to count downward.
4. In the first thread:
   - Start counting at 1.
   - Display the current number.
   - Wait for a short period.
   - Increase the number by 1.
   - Repeat until the number reaches 20.
5. In the second thread:
   - Start counting at 20.
   - Display the current number.
   - Wait for a short period.
   - Decrease the number by 1.
   - Repeat until the number reaches 0.
6. Start both threads.
7. Wait for both threads to finish.
8. End the program.
